Run the rig

Run starts the trained policy balancing the pole: the Orin's brain takes each camera frame, finds the markers, asks the policy for a speed, and sends it to the board, until STOP or until the board goes into FAULT. One press of Run is one run, with no time limit.

Stand at the e-stop before pressing Run: the cart moves fast. STOP below asks over WiFi, and a message can be lost, so it does not replace the e-stop.

How to read this

When Run can be pressed. Only when the brain is idle and the board says it is calibrated: it knows where both ends of the rail are, and the cart is at rest. The board learns the rail on the calibrate page: find both ends, then move to the centre. Beside a greyed-out Run is the reason. A board that was reset, or switched off, starts uncalibrated. A board in FAULT stays there until it is reset, and then needs calibrating again. Before Run, the pole should hang still.

The brain may still refuse Run, and the line under the buttons then says why: the camera is in use by the live view or a calibration measurement, or the camera's matrix, homography.json, did not pass its fit and was not accepted on the calibrate page.

How a run ends. Only two things end it. STOP: the webserver first asks the brain to stop sending, and once it has, sends the board the command 0, a speed of zero, several times, since any one message can be lost on the WiFi; the board slows the cart to rest. The zeros go out even if the brain does not answer, so a brain that has crashed cannot keep the cart moving. Or a FAULT: the board stops the cart by itself when it enters the protected zone near either end of the rail, or gets a command it cannot read, and answers every message after that with its FAULT reply. The brain then stops, and Last message says which ended the run: stopped, or the board's FAULT with where the cart stopped, in motor pulses from the idler end.

Re-centre. Moves the cart back to the middle of the rail, from wherever a run left it, at the board's seek speed, 2,000 motor pulses a second, which is 30 mm a second, so about 15 s from an end. The board knows where the cart is by counting its pulses, so it needs no switch to do this. It can be pressed when Run can, and greys out both buttons until the cart has stopped. STOP ends it too: STOP always also sends the board Stop, the only message it listens to during the move. A Re-centre that is stopped, or that trips a switch on the way, leaves the board calibrating, and Run waits until a Re-centre arrives; after a tripped switch the board has forgotten the rail, so calibrate again on the calibrate page.

The state. Brain is Running or Idle. Last message is why the last run ended, or why Run was refused. Frames this run is how many camera frames the brain has turned into a command, about 30 each second. Run folder is where the run's log is written on the Orin, frames.jsonl, one line per frame, named by the time Run was pressed (UTC). Board is the board's own answer to state. During a run the board is not asked: the brain alone talks to it then.

When the state is read. When the page opens, and after each press of Run, Re-centre or STOP. Reload the page to read it again.
